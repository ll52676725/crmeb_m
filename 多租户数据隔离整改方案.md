# CRMEB电商系统多租户数据隔离整改方案

## 一、方案概述

### 1.1 背景

CRMEB电商系统是一个基于Spring Boot + MyBatis-Plus的单体电商系统，在多租户部署上线后，由于缺乏完善的多租户数据隔离机制，导致以下问题：

1. **数据安全风险**：租户之间数据未有效隔离，存在数据泄露风险
2. **性能瓶颈**：所有租户数据共享同一数据库表，数据量增长导致查询性能下降
3. **维护困难**：无法针对单个租户进行数据备份、恢复和迁移
4. **扩展限制**：无法实现按租户粒度的水平扩展

### 1.2 目标

本方案旨在为CRMEB电商系统设计并实施一套完整的多租户数据隔离机制，实现：

1. **数据安全**：确保租户之间数据完全隔离，禁止跨租户数据访问
2. **性能优化**：通过合理的数据隔离策略提升系统在多租户场景下的性能
3. **可维护性**：支持租户级别的数据管理（备份、恢复、迁移）
4. **可扩展性**：支持系统在租户数量增长时的水平扩展

## 二、多租户隔离方案选型

### 2.1 主流方案对比

| 方案 | 隔离级别 | 实现复杂度 | 性能 | 数据安全 | 适用场景 |
|------|----------|------------|------|----------|----------|
| 共享数据库+共享表+租户字段 | 低 | 低 | 中 | 中 | 中小型租户（<100个） |
| 共享数据库+独立表 | 中 | 中 | 中 | 中 | 中型租户（100-1000个） |
| 独立数据库 | 高 | 高 | 高 | 高 | 大型租户（>1000个或VIP租户） |

### 2.2 推荐方案

根据CRMEB系统的业务特点和多租户规模，推荐采用**"共享数据库+共享表+租户字段"**的方案，理由如下：

1. **实现成本低**：基于MyBatis-Plus租户插件，改动量小
2. **兼容性好**：与现有代码结构兼容性高
3. **维护简单**：统一的数据库维护策略
4. **扩展性强**：后期可无缝升级为独立数据库方案

**特殊场景处理**：
- 对于VIP租户或数据量特别大的租户，可单独分配独立数据库
- 系统配置表（如`eb_system_config`）可考虑作为公共表，不参与租户隔离

#### 3.2.2 租户标识解析

**模块位置**：`crmeb-common/src/main/java/com/zbkj/common/interceptor/`

**核心类**：

1. **TenantInterceptor** - 租户拦截器
```java
package com.zbkj.common.interceptor;

import com.zbkj.common.exception.CrmebException;
import com.zbkj.common.tenant.TenantContextHolder;
import org.springframework.web.servlet.HandlerInterceptor;

import javax.servlet.http.HttpServletRequest;
import javax.servlet.http.HttpServletResponse;

public class TenantInterceptor implements HandlerInterceptor {

    private static final String TENANT_ID_HEADER = "X-Tenant-Id";
    private static final String TENANT_ID_PARAM = "tenantId";

    @Override
    public boolean preHandle(HttpServletRequest request, HttpServletResponse response, Object handler) throws Exception {
        String tenantIdStr = request.getHeader(TENANT_ID_HEADER);
        if (tenantIdStr == null || tenantIdStr.isEmpty()) {
            tenantIdStr = request.getParameter(TENANT_ID_PARAM);
        }

        if (tenantIdStr != null && !tenantIdStr.isEmpty()) {
            try {
                Integer tenantId = Integer.parseInt(tenantIdStr);
                TenantContextHolder.setTenantId(tenantId);
            } catch (NumberFormatException e) {
                throw new CrmebException("无效的租户标识");
            }
        } else {
            Object tenantId = request.getAttribute("tenantId");
            if (tenantId != null) {
                TenantContextHolder.setTenantId((Integer) tenantId);
            }
        }

        return true;
    }

    @Override
    public void afterCompletion(HttpServletRequest request, HttpServletResponse response, Object handler, Exception ex) throws Exception {
        TenantContextHolder.clear();
    }
}
```

1. **MybatisPlusTenantConfig** - MyBatis-Plus租户配置
```java
package com.zbkj.common.config;

import com.baomidou.mybatisplus.extension.plugins.MybatisPlusInterceptor;
import com.baomidou.mybatisplus.extension.plugins.handler.TenantLineHandler;
import com.baomidou.mybatisplus.extension.plugins.inner.TenantLineInnerInterceptor;
import com.zbkj.common.exception.CrmebException;
import com.zbkj.common.tenant.TenantContextHolder;
import net.sf.jsqlparser.expression.Expression;
import net.sf.jsqlparser.expression.LongValue;
import net.sf.jsqlparser.expression.NullValue;
import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;

import java.util.Arrays;
import java.util.List;

@Configuration
public class MybatisPlusTenantConfig {

    private static final String TENANT_ID_COLUMN = "tenant_id";

    private static final List<String> IGNORE_TABLES = Arrays.asList(
            "eb_system_tenant",
            "eb_system_config",
            "eb_system_menu",
            "eb_system_role",
            "eb_system_permissions",
            "eb_system_city",
            "eb_express",
            "eb_category"
    );

    @Bean
    public MybatisPlusInterceptor mybatisPlusInterceptor() {
        MybatisPlusInterceptor interceptor = new MybatisPlusInterceptor();
        interceptor.addInnerInterceptor(new TenantLineInnerInterceptor(new TenantLineHandler() {
            @Override
            public Expression getTenantId() {
                if (TenantContextHolder.isIgnoreTenant()) {
                    return new NullValue();
                }
                Integer tenantId = TenantContextHolder.getTenantId();
                if (tenantId == null) {
                    throw new CrmebException("租户标识不存在");
                }
                return new LongValue(tenantId);
            }

            @Override
            public String getTenantIdColumn() {
                return TENANT_ID_COLUMN;
            }

            @Override
            public boolean ignoreTable(String tableName) {
                if (TenantContextHolder.isIgnoreTenant()) {
                    return true;
                }
                return IGNORE_TABLES.contains(tableName);
            }
        }));
        return interceptor;
    }
}
```

#### 3.2.4 自定义SQL处理

由于项目中存在大量自定义SQL（如`${where}`动态SQL），需要特殊处理：

1. **动态SQL拦截器** - 处理`${where}`等动态SQL
```java
package com.zbkj.common.interceptor;

import org.apache.ibatis.executor.statement.StatementHandler;
import org.apache.ibatis.plugin.*;
import org.apache.ibatis.reflection.MetaObject;
import org.apache.ibatis.reflection.SystemMetaObject;
import org.springframework.stereotype.Component;

import java.sql.Connection;
import java.util.Properties;

@Component
@Intercepts({@Signature(type = StatementHandler.class, method = "prepare", args = {Connection.class, Integer.class})})
public class DynamicSqlInterceptor implements Interceptor {

    @Override
    public Object intercept(Invocation invocation) throws Throwable {
        StatementHandler statementHandler = (StatementHandler) invocation.getTarget();
        MetaObject metaObject = SystemMetaObject.forObject(statementHandler);
        
        String originalSql = (String) metaObject.getValue("delegate.boundSql.sql");
        
        String modifiedSql = processSql(originalSql);
        
        metaObject.setValue("delegate.boundSql.sql", modifiedSql);
        
        return invocation.proceed();
    }

    private String processSql(String sql) {
        return sql;
    }

    @Override
    public Object plugin(Object target) {
        return Plugin.wrap(target, this);
    }

    @Override
    public void setProperties(Properties properties) {
    }
}
```

2. **WhereSqlInjector** - 处理自定义SQL中的`${where}`
```java
package com.zbkj.common.mybatis;

import com.baomidou.mybatisplus.core.injector.AbstractMethod;
import com.baomidou.mybatisplus.core.injector.DefaultSqlInjector;
import com.baomidou.mybatisplus.core.metadata.TableInfo;
import com.zbkj.common.tenant.TenantContextHolder;
import org.springframework.stereotype.Component;

import java.util.List;

@Component
public class TenantSqlInjector extends DefaultSqlInjector {

    @Override
    public List<AbstractMethod> getMethodList(Class<?> mapperClass, TableInfo tableInfo) {
        List<AbstractMethod> methodList = super.getMethodList(mapperClass, tableInfo);
        return methodList;
    }

    public static String appendTenantCondition(String sql, String tableAlias) {
        if (TenantContextHolder.isIgnoreTenant()) {
            return sql;
        }
        Integer tenantId = TenantContextHolder.getTenantId();
        if (tenantId == null) {
            return sql;
        }
        
        String alias = tableAlias != null && !tableAlias.isEmpty() ? tableAlias + "." : "";
        String tenantCondition = alias + "tenant_id = " + tenantId;
        
        if (sql.toLowerCase().contains("where")) {
            return sql.replaceFirst("(?i)where", "WHERE " + tenantCondition + " AND ");
        } else {
            if (sql.toLowerCase().contains("group by") || 
                sql.toLowerCase().contains("order by") || 
                sql.toLowerCase().contains("limit")) {
                return sql.replaceFirst("(?i)(group by|order by|limit)", "WHERE " + tenantCondition + " $1");
            } else {
                return sql + " WHERE " + tenantCondition;
            }
        }
    }
}
```

#### 3.2.5 缓存层租户隔离

**模块位置**：`crmeb-common/src/main/java/com/zbkj/common/utils/`

**改造RedisUtil**：

```java
package com.zbkj.common.utils;

import com.zbkj.common.tenant.TenantContextHolder;
import org.springframework.data.redis.core.ListOperations;
import org.springframework.data.redis.core.RedisTemplate;
import org.springframework.data.redis.core.SetOperations;
import org.springframework.data.redis.core.ZSetOperations;
import org.springframework.stereotype.Component;

import javax.annotation.Resource;
import java.util.List;
import java.util.Set;
import java.util.concurrent.TimeUnit;

@Component
public class RedisUtil {

    @Resource
    private RedisTemplate<String, Object> redisTemplate;

    private static final String TENANT_PREFIX = "tenant:";

    private String buildKey(String key) {
        if (TenantContextHolder.isIgnoreTenant()) {
            return key;
        }
        Integer tenantId = TenantContextHolder.getTenantId();
        if (tenantId == null) {
            return key;
        }
        return TENANT_PREFIX + tenantId + ":" + key;
    }

    public boolean expire(String key, long time) {
        try {
            if (time > 0) {
                redisTemplate.expire(buildKey(key), time, TimeUnit.SECONDS);
            }
            return true;
        } catch (Exception e) {
            e.printStackTrace();
            return false;
        }
    }

    public long getExpire(String key) {
        return redisTemplate.getExpire(buildKey(key), TimeUnit.SECONDS);
    }

    public boolean exists(String key) {
        try {
            return redisTemplate.hasKey(buildKey(key));
        } catch (Exception e) {
            e.printStackTrace();
            return false;
        }
    }

    public void delete(String key) {
        String actualKey = buildKey(key);
        if (redisTemplate.hasKey(actualKey)) {
            redisTemplate.delete(actualKey);
        }
    }

    public boolean set(String key, Object value) {
        try {
            redisTemplate.opsForValue().set(buildKey(key), value);
            return true;
        } catch (Exception e) {
            e.printStackTrace();
            return false;
        }
    }

    public boolean set(String key, Object value, Long expireTime) {
        try {
            if (expireTime > 0) {
                redisTemplate.opsForValue().set(buildKey(key), value, expireTime, TimeUnit.SECONDS);
            } else {
                set(key, value);
            }
            return true;
        } catch (Exception e) {
            e.printStackTrace();
            return false;
        }
    }

    public boolean set(String key, Object value, Long expireTime, TimeUnit timeUnit) {
        try {
            redisTemplate.opsForValue().set(buildKey(key), value, expireTime, timeUnit);
            return true;
        } catch (Exception e) {
            e.printStackTrace();
            return false;
        }
    }

    @SuppressWarnings("unchecked")
    public <T> T get(String key) {
        return (T) redisTemplate.opsForValue().get(buildKey(key));
    }

    public void hmSet(String key, Object hashKey, Object value) {
        redisTemplate.opsForHash().put(buildKey(key), hashKey, value);
    }

    public void hmDelete(String key, Object hashKey) {
        redisTemplate.opsForHash().delete(buildKey(key), hashKey);
    }

    public Object hmGet(String key, Object hashKey) {
        return redisTemplate.opsForHash().get(buildKey(key), hashKey);
    }

    public Long getHashSize(String key) {
        return redisTemplate.opsForHash().size(buildKey(key));
    }

    public void lPush(String k, Object v) {
        ListOperations<String, Object> list = redisTemplate.opsForList();
        list.leftPush(buildKey(k), v);
    }

    public Object getRightPop(String k, Long t) {
        return redisTemplate.opsForList().rightPop(buildKey(k), t, TimeUnit.SECONDS);
    }

    public Long getListSize(String k) {
        return redisTemplate.opsForList().size(buildKey(k));
    }

    public List<Object> lRange(String k, long l, long l1) {
        ListOperations<String, Object> list = redisTemplate.opsForList();
        return list.range(buildKey(k), l, l1);
    }

    public void add(String key, Object value) {
        SetOperations<String, Object> set = redisTemplate.opsForSet();
        set.add(buildKey(key), value);
    }

    public Set<Object> setMembers(String key) {
        SetOperations<String, Object> set = redisTemplate.opsForSet();
        return set.members(buildKey(key));
    }

    public void zAdd(String key, Object value, double score) {
        ZSetOperations<String, Object> zset = redisTemplate.opsForZSet();
        zset.add(buildKey(key), value, score);
    }

    public Set<Object> rangeByScore(String key, double score, double score1) {
        ZSetOperations<String, Object> zset = redisTemplate.opsForZSet();
        return zset.rangeByScore(buildKey(key), score, score1);
    }

    public long incrAndCreate(String key) {
        String actualKey = buildKey(key);
        if (!exists(key)) {
            set(key, 1);
            return 1;
        }
        return incr(key, 1L);
    }

    public long incr(String key, long delta) {
        if (delta < 0) {
            throw new RuntimeException("递增因子必须大于0");
        }
        return redisTemplate.opsForValue().increment(buildKey(key), delta);
    }
}
```

#### 3.2.6 定时任务租户隔离

1. **TenantTaskDecorator** - 任务装饰器，传递租户上下文
```java
package com.zbkj.common.task;

import com.zbkj.common.tenant.TenantContextHolder;
import org.springframework.core.task.TaskDecorator;

public class TenantTaskDecorator implements TaskDecorator {

    @Override
    public Runnable decorate(Runnable runnable) {
        Integer tenantId = TenantContextHolder.getTenantId();
        return () -> {
            try {
                if (tenantId != null) {
                    TenantContextHolder.setTenantId(tenantId);
                }
                runnable.run();
            } finally {
                TenantContextHolder.clear();
            }
        };
    }
}
```

```java
import com.zbkj.common.tenant.TenantContextHolder;

public class TenantRunnable implements Runnable {

    private final Integer tenantId;

    public TenantRunnable(Runnable delegate, Integer tenantId) {
        this.delegate = delegate;
        this.tenantId = tenantId;

            if (tenantId != null) {
                TenantContextHolder.setTenantId(tenantId);
            }
            delegate.run();
        } finally {
            TenantContextHolder.clear();
        }
    }
}
```

## 五、风险与应对措施

### 5.1 主要风险

| 风险项 | 影响程度 | 发生概率 | 应对措施 |
|--------|----------|----------|----------|
| 数据库变更导致数据丢失 | 高 | 中 | 执行前全量备份，分批执行 |
| 自定义SQL遗漏租户条件 | 高 | 高 | 全面扫描，代码审查，自动化测试 |
| 性能下降 | 中 | 中 | 添加索引，优化查询，读写分离 |
| 缓存数据不一致 | 中 | 中 | 清理旧缓存，双写策略 |
| 定时任务数据异常 | 中 | 中 | 测试覆盖，监控告警 |

### 5.2 详细应对措施

#### 5.2.1 数据库变更风险应对

1. **全量备份**：
   - 执行DDL前进行全量数据库备份
   - 备份文件验证完整性

2. **分批执行**：
   - 先在测试环境执行
   - 再在预生产环境执行
   - 最后在生产环境执行

3. **回滚方案**：
   - 准备完整的回滚脚本
   - 验证回滚脚本的正确性

#### 5.2.2 自定义SQL遗漏风险应对

1. **全面扫描**：
   - 使用Grep工具扫描所有`${where}`
   - 扫描所有`@Select`注解的原生SQL
   - 扫描所有`sqlSession.select()`调用

2. **代码审查**：
   - 建立审查清单
   - 双人交叉审查
   - 重点关注统计查询和报表SQL

3. **自动化测试**：
   - 编写SQL验证测试
   - 对比改造前后的查询结果
   - 集成测试覆盖主要业务流程

#### 5.2.3 性能下降风险应对

1. **索引优化**：
   - 为所有tenant_id字段添加索引
   - 分析慢查询日志
   - 优化高频查询

2. **查询优化**：
   - 避免全表扫描
   - 优化关联查询
   - 使用分页查询

3. **读写分离**：
   - 配置主从复制
   - 读操作走从库
   - 写操作走主库

#### 5.2.4 缓存数据不一致风险应对

1. **缓存清理策略**：
   - 上线前清理所有旧缓存
   - 或者使用不同的Redis数据库

2. **双写策略**：
   - 过渡期同时读写新旧缓存
   - 逐步淘汰旧缓存

3. **缓存失效策略**：
   - 设置合理的过期时间
   - 数据变更时主动失效缓存

### 6.4 SQL优化

#### 6.4.1 避免N+1查询

**优化前**：
```java
List<StoreOrder> orders = orderService.list();
for (StoreOrder order : orders) {
    User user = userService.getById(order.getUid());
    order.setUser(user);
}
```

**优化后**：
```java
List<StoreOrder> orders = orderService.list();
if (CollUtil.isNotEmpty(orders)) {
    List<Integer> uidList = orders.stream()
            .map(StoreOrder::getUid)
            .distinct()
            .collect(Collectors.toList());
    List<User> userList = userService.listByIds(uidList);
    Map<Integer, User> userMap = userList.stream()
            .collect(Collectors.toMap(User::getUid, Function.identity()));
    for (StoreOrder order : orders) {
        order.setUser(userMap.get(order.getUid()));
    }
}
```

```java
@Override
public boolean preHandle(HttpServletRequest request, HttpServletResponse response, Object handler) throws Exception {
    Integer tenantId = TenantContextHolder.getTenantId();
    if (tenantId != null) {
        MDC.put("tenantId", tenantId.toString());
    } else {
        MDC.put("tenantId", "unknown");
    }
    return true;
}

@Override
public void afterCompletion(HttpServletRequest request, HttpServletResponse response, Object handler, Exception ex) throws Exception {
    MDC.remove("tenantId");
    TenantContextHolder.clear();
}
```
